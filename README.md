Project name: FitLog


Short description:
Fitlog is a workout application. User can browse a workout library, view details information, add todays plan or saved for later and sort workout list.

Technologies used:
1. Next.js
2. React
3. Typescript
4. Tailwind CSS
5. Daisy UI
6. API
7. React Toastify

5 key features of the project:
1. Workout Library
2. Details Information
3. Add to Todays plan
4. Save for Later
5. Sorting Functionality
